# Carrinho de Compras - Projeto Interativo

Este é um projeto prático de um **Carrinho de Compras** desenvolvido para simular a lógica de e-commerce. A aplicação permite selecionar produtos, definir quantidades, adicionar itens a uma lista dinâmica e calcular o valor total em tempo real.

---

##  Tecnologias Utilizadas

O projeto foi construído utilizando as tecnologias fundamentais da web:

* **HTML5:** Estruturação semântica de formulários e seções.
* **CSS3:** Estilização personalizada, fontes modernas (*Chakra Petch* e *Inter*) e layout responsivo.
* **JavaScript:** Lógica de programação para manipulação do DOM, cálculos matemáticos e atualização de interface.

---

##  Funcionalidades

- [x] **Seleção de Produtos:** Menu suspenso com opções de itens e preços.
- [x] **Entrada de Quantidade:** Campo numérico para definir quantas unidades adicionar.
- [x] **Cálculo Dinâmico:** Multiplicação automática de `Preço × Quantidade`.
- [x] **Somatório Total:** Exibição do valor total acumulado no carrinho.
- [x] **Reset de Carrinho:** Função para limpar a lista e zerar o contador.
